Portfolio Listings

How Quarto Listings turn a set of projects into a browsable portfolio

What Is a Listing?

A listing is a page that automatically gathers items and shows them as cards, a list, or a table. Quarto can pull items from a folder of pages or from a YAML file, and builds the titles, images, dates, and categories into a browsable index.

That makes listings ideal for a portfolio: add a new item, re-render, and it appears.

How It Works

My two projects already live on their own published sites, so instead of making a page for each one, I listed them in a single YAML file and pointed each item’s path to its live URL.

  1. Create a YAML file for your items, such as portfolio/items.yml.
  2. Add one entry per project with a title, description, link, image, date, and categories.
  3. Add a listing: block to the page that should display them.
  4. Place a div with the listing’s id where the listing should appear.

Step 2: One project entry

portfolio/items.yml
- title: "Farm Store Social Content Strategy"
  subtitle: "OptiMark × Farm Store"
  path: https://lewiswaddell.github.io/OptimarkxFarmstoreStrategy/
  image: portfolio/farmstore.png
  date: 2026-11-01
  categories: [Social Media, Content Strategy, OptiMark]

Step 3: The listing block on this page

listings.qmd
listing:
  - id: portfolio-grid
    contents: portfolio/items.yml   # where the items come from
    type: grid                      # default, grid, or table
    sort: "date desc"               # newest first
    categories: true                # clickable category filter
    fields: [image, title, subtitle, description, categories, date]

Step 4: Where it appears

::: {#portfolio-grid}
:::

Three Listing Types

Type Looks like Best for
default A blog style list with a thumbnail beside each entry Blogs and news posts
grid Cards in columns Visual portfolios (used above)
table A sortable, searchable table Long lists people need to scan

Useful Listing Options

  • contents: a folder, a YAML file, a list of files, or a pattern like "posts/*.qmd".
  • sort: order items by date, title, or any field, ascending or descending.
  • categories: show a clickable category list built from each item’s tags.
  • filter-ui and sort-ui: add a search box and sort menu for visitors.
  • page-size: split long listings into pages.
  • feed: true: create an RSS feed so followers get your new posts.
